# Weekly meal-insights email

Homebase now keeps the existing `Swap Log` and `Meal History` tabs as an audit
trail while maintaining three clean reporting tabs:

- `Meal Feedback` — append-only confirmations and changes, including reason.
- `Meal Outcomes` — one normalized planned-versus-actual record per meal.
- `Meal Aliases` — editable alias-to-canonical mappings such as
  `Tacos (home)` → `Tacos`.

The touchscreen asks the family to either confirm the displayed meal or choose a
reason before replacing it. Menu-managed dates and generated schedule dates use
the same feedback path.

## Email delivery

The report is generated by `GET /api/meal/report` and sent from the family's
Google account by Apps Script. The first email includes the algorithm baseline;
later emails contain the rolling 28-day review only.

1. Add `MEAL_REPORT_SECRET` to Vercel Production and Preview. Use a long random
   value and redeploy.
2. In the existing **Homebase School Import** Apps Script project, add a new
   script file and paste `automation/meal-insights-email.gs` into it.
3. Open Apps Script **Project Settings → Script Properties** and add:
   - `HOMEBASE_BASE_URL` = the production Homebase URL, without a trailing slash.
   - `MEAL_REPORT_SECRET` = the same secret stored in Vercel.
   - `MEAL_REPORT_RECIPIENTS` = comma-separated recipient addresses.
4. Run `setupWeeklyMealInsights` once and approve Gmail/external-request access.
5. Run `sendWeeklyMealInsights` once to send the baseline report immediately.

The setup function replaces only the existing `sendWeeklyMealInsights` trigger.
It does not touch the hourly school-email trigger. The new report runs on Monday
mornings around 7:00 in the Apps Script project's timezone.

## Reporting safeguards

- One change is not enough to recommend reducing a recipe.
- Reduce/retire suggestions require at least three recorded appearances and at least
  two recorded changes with a 50% or greater change rate.
- Confirmed, assumed, and legacy outcomes are shown separately.
- Assumed outcomes are excluded from recipe-weight recommendations.
- Original logs are never deleted or rewritten by the cleanup layer.
